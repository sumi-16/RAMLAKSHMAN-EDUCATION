# RamLakshman Education

A free static website starter for bilingual (Telugu + English) APPSC current-affairs learning.

## Open locally
Open `index.html` in a modern browser.

## Included
- Daily Current Affairs and AP Special sections
- Daily MCQ quiz with answer feedback
- Browser-local bookmarks
- Monthly PDF placeholder
- Group 1 / Group 2 syllabus starter section
- Add-post and add-question editor

## Important
The Add Content editor uses browser localStorage. It saves only in the current browser/device; it does not publish to all visitors and is not a secure shared admin system. For public updates, edit the website content and redeploy, or connect a CMS/database with authentication.

The sample entries are demonstrations, not verified daily news. Verify facts and add trustworthy source links before publishing. Do not copy publishers' articles verbatim.
